Controllers pour ros humble - gazebo harmonic (pkg gz_ros2_control) :

mkdir -p ~/gz_ros2_control_ws/src
cd ~/gz_ros2_control_ws/src
git clone https://github.com/ros-controls/gz_ros2_control -b humble
export GZ_VERSION=harmonic
rosdep update
rosdep install -r --from-paths . --ignore-src --rosdistro $ROS_DISTRO -y --skip-keys="ros_gz_bridge ros_gz_sim"
cd ~/gz_ros2_control_ws
colcon build

colcon build --packages-select gz_ros2_control --cmake-clean-cache

Car :

L’export du plugin est protégé par une condition préprocesseur :

"#ifdef GZ_HEADERS
GZ_ADD_PLUGIN(...)
GZ_ADD_PLUGIN_ALIAS(...)
#endif"

Or si GZ_HEADERS n’est pas défini au moment de la compilation, cette partie n’est pas compilée, et le symbole GzPluginHook est absent
Et GZ_HEADERS est défini uniquement si GZ_VERSION==harmonic
"if("$ENV{GZ_VERSION}" STREQUAL "harmonic")
  ...
  add_definitions(-DGZ_HEADERS)"
  
  Autre (osef à priori) :
  
(ros2 run controller_manager ros2_control_node --ros-args -p robot_description:="$(cat ~/turtlebot3_ws/src/summit_xl_description/robots/summit_xl_std.urdf)" --params-file ~/turtlebot3_ws/src/summit_xl_description/config/summit_control.yaml) => pas nécessaire à priori
